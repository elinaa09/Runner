#Features
-Animated running character (3 frames, swapping while you run)
-A different picture for the character while jumping
-Three kinds of  obstacles that appear at random
-Snowflakes to collect, some on the ground and some in the air
-Score and high score
-Menu page with a hamburger menu for settings
-Sound on or off
-Normal or Hard difficulty (hard is faster and has more snowglobes)
-Background music and sound effects
-The game scales to fit any window size

#How it works
-runner.js runs a loop that moves the player, the snowglobes and the         snowflakes, draws everything, and checks for collisions.
-The menu and the game share settings (sound, difficulty and high score) through localStorage.
-Hard mode makes everything move faster and spawns snowglobes more often.

What I learned
-Drawing and animating images on a canvas
-Game loops with requestAnimationFrame
-Collision detection between rectangles
-Saving data with localStorage
-Debugging file paths, variable order and 404 errors
